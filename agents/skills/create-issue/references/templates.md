# Issueテンプレート

本文ドラフトの雛形。プレースホルダー（`[...]`）を実際の値に置き換える。情報がないセクションは省略してよい。

## Bug Report

```markdown
## 概要

[何が起きているか]

## 再現手順

1. [手順]
2. [手順]
3. [手順]

## 期待される動作

[本来どうなるべきか]

## 実際の動作

[実際に何が起きるか]

## 環境

- OS: [例: macOS 14.0]
- バージョン: [例: v1.2.3]

## 補足

[ログ・スクリーンショット・関連情報]
```

## Feature Request

```markdown
## 概要

[機能の1行説明]

## 動機

[なぜ必要か。どんな問題を解決するか]

## 提案する解決策

[どう動くべきか]

## 受け入れ条件

- [ ] [条件1]
- [ ] [条件2]

## 補足

[モックアップ・例・関連Issue]
```

## Task

```markdown
## 目的

[何を達成するか]

## 詳細

[作業内容の説明]

## チェックリスト

- [ ] [サブタスク1]
- [ ] [サブタスク2]

## 補足

[ブロッカー・関連する作業]
```
